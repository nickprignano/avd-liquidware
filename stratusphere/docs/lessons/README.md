# Lessons

Lessons from real runs now live in the knowledge base: on the topic page they belong to under
[docs/knowledge/](../../../docs/knowledge/README.md), and errors with a known cause in
[known-errors.yaml](../../../docs/knowledge/troubleshooting/known-errors.yaml). Each lesson still
adds a guard (a Pester test or a preflight check), per
[decision 0007](../../../docs/knowledge/decisions/0007-real-runs-are-the-source-of-truth.md).
